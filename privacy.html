Privacy Policy

Strange Spoon Uploader · Last updated: October 9, 2026

Strange Spoon Uploader ("the app") is a private automation tool used only by the owner of the Strange Spoon YouTube channel to upload that channel's own videos. It is not offered to the public.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • Google Drive: the app reads the owner's own video clips and text files from one designated Drive folder, and moves processed folders within it.
  • YouTube: the app uploads videos and their titles, descriptions and tags to the owner's own channel.

How data is used and stored

Data is used only to assemble and publish the owner's videos. Files are processed temporarily on the build server and deleted when each run ends. The app does not collect data from viewers or any other user, does not sell or share data with third parties, and does not use it for advertising. OAuth credentials are stored as encrypted secrets and are never published.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.
